## 1. Flash

Download the image for **your exact hardware revision** from the OpenWrt firmware selector.

## 2. Connect

Plug into a LAN port and open `http://192.168.1.1`.

## 3. Secure

1. **Set a root password** (System → Administration).
2. **Add an SSH key** and disable password login.
3. **Apply the** [Secure Baseline](/openwrt/configs/secure-baseline) config.
